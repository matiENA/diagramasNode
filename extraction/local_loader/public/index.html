⚡ Integración con n8n

Este servidor local expone una API REST limpia y documentada que permite a tus flujos de n8n orquestar extracciones, inspeccionar datos y disparar inyecciones mediante nodos HTTP Request.

POST
/api/extract/:module

Descarga de Google Sheets a JSON local sin escribir en Supabase.

Módulos válidos: all, master, vencimientos, flota, diagramas, kilometros, legajos 
curl -X POST http://localhost:3010/api/extract/flota
POST
/api/inject/:module

Lee el JSON local y lo inserta/upserta en Supabase.

Opciones en Body o Query: dryRun=true para simular sin escribir. 
curl -X POST http://localhost:3010/api/inject/flota \
  -H "Content-Type: application/json" \
  -d '{"dryRun": false}'
POST
/api/sync/:module

Ejecuta extracción e inyección encadenadas en un solo paso.

Webhook opcional: Recibe el resultado final en n8n al completar. 
curl -X POST http://localhost:3010/api/sync/all \
  -H "Content-Type: application/json" \
  -d '{"webhookUrl": "http://tu-n8n:5678/webhook/etl-done"}'
GET
/api/data/:module

Retorna los datos JSON extraídos localmente para que n8n los procese.

curl http://localhost:3010/api/data/flota
GET
/api/status

Consulta el estado del servidor, si está ocupado y las fechas de última sincronización.

curl http://localhost:3010/api/status

🛠️ Cómo configurar un nodo HTTP Request en n8n:

  1. Method: POST
  2. URL: http://localhost:3010/api/sync/all (o la IP de tu PC en tu red local si n8n corre en Docker: http://host.docker.internal:3010/api/sync/all)
  3. Body Parameters: JSON con {"dryRun": false}
  4. Timeout: Configurar en 300000 ms (5 minutos) para permitir la extracción masiva de diagramas y kilómetros.
